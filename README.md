# ExplorerGesture

轻量、纯绿色、零注册表修改的 **Windows 文件资源管理器专属鼠标右键手势工具**，支持 Windows 10 / 11（含新版多标签页资源管理器），内置平滑抗锯齿蓝色轨迹与实时方向箭头。

---

## 核心特性

- **纯绿色便携，零注册表修改**：无需安装环境，不读写任何 `HKCU` / `HKLM` 注册表项，不修改系统文件，随时一键停用清理无残留。
- **仅在资源管理器窗口生效**：精准作用于文件资源管理器（`CabinetWClass`），在文件重命名编辑框（`Edit`）内自动放行原生菜单，不干扰桌面、浏览器、编辑器或游戏中的右键操作。
- **平滑抗锯齿轨迹 + 跟随箭头**：基于 Windows 原生 `GDI+` 与 `DWM` 分层鼠标穿透透明画布绘制样条曲线和流线型箭头，自适应高分屏 DPI 缩放与多显示器环境。
- **复杂/杂乱手势自动作废（防误触）**：内置路径曲折比、方向折返与横向摆幅检测；滑动中途若想取消，随手折返或画圈即可实时变灰作废，松手后既不跳转也不弹出右键菜单。
- **全输入设备兼容**：采用成对低级鼠标钩子事件追踪，同时兼容物理鼠标、笔记本精密触控板、远程控制软件及各类外设驱动。
- **无感静默常驻**：默认隐藏系统托盘图标，后台内存占用仅约 `2~3 MB`，空闲 CPU 占用 `0%`。

## 手势功能一览

| 手势操作 | 触发动作 | 详细说明 |
| :--- | :--- | :--- |
| **左滑 (`←`)** | 返回上一级目录 | 等效 `Alt + Up`，并自动记忆退出的下一级目录 |
| **右滑 (`→`)** | 进入下一级目录 | 进入当前单选的子文件夹，或重新进入刚退出的直接子目录 |
| **上滑 (`↑`)** | 历史记录回退（上一个） | 当前活动标签页后退 |
| **下滑 (`↓`)** | 历史记录前进（下一个） | 当前活动标签页前进 |
| **原地单击右键** | 系统原生右键菜单 | 正常弹出 Windows 右键上下文菜单 |
| **长按右键 (`≥ 280 ms`)** | 系统原生右键拖拽 | 按住停顿达 `280 ms` 自动转交系统原生右键拖拽操作 |
| **折返 / 画圈 / 乱划** | 自动取消（轨迹变灰） | 杂乱复杂手势松手后直接作废，零误触 |

## 快速使用

1. 下载本仓库代码（或 Release 压缩包），解压到任意固定文件夹。
2. **启动并开启开机自启**：
   双击运行 `Start_And_Enable_Startup.cmd`。脚本会自动解除系统网络下载安全锁定（`Zone.Identifier`），在当前用户的系统启动文件夹（`Startup`）下创建快捷方式，并在后台静默启动手势进程。
   > 若仅需单次临时体验、不想设置开机自启，直接双击 `ExplorerGesture.exe` 即可。
3. **停用并清理开机自启**：
   双击运行 `Stop_And_Remove_Startup.cmd`，即可立即终止后台进程并移除启动文件夹下的快捷方式，不留任何系统痕迹。

## 目录文件说明

| 文件名 | 说明 |
| :--- | :--- |
| `ExplorerGesture.exe` | 64 位便携运行宿主（基于官方 AutoHotkey v2 64-bit 解释器） |
| `ExplorerGesture.ahk` | 手势识别、多标签页 `IShellBrowser` 导航及 `GDI+` 轨迹渲染核心源码（`UTF-8 with BOM`） |
| `Start_And_Enable_Startup.cmd` | 一键后台启动并添加开机自启脚本 |
| `Stop_And_Remove_Startup.cmd` | 一键停止进程并移除开机自启脚本 |
| `license.txt` | 开源许可证文件（GPL-2.0） |

---

## 自定义修改

可直接用任意代码编辑器修改同目录下的 `ExplorerGesture.ahk`（注意保存编码需保持 **`UTF-8 with BOM`**）。修改完成后再次双击 `ExplorerGesture.exe`（或 `Start_And_Enable_Startup.cmd`），新实例会自动平滑替换旧实例生效。
